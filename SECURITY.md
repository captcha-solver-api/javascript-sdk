# Security Policy

## Supported versions

Security fixes are provided for the latest `1.x` release of the SDK.

| Version | Supported |
|---|---|
| 1.x | Yes |
| < 1.0 | No |

## Reporting a vulnerability

Please do not report security vulnerabilities in public GitHub issues.

Use GitHub's private vulnerability reporting instead:

1. Open the repository's **Security** tab.
2. Select **Advisories**.
3. Select **Report a vulnerability**.

Include the affected SDK version, a clear description of the issue, steps to
reproduce it, and its potential impact. If possible, include a minimal proof of
concept and any suggested mitigation.

We will acknowledge the report, investigate it, and coordinate disclosure with
the reporter. Please allow time for a fix to be prepared and released before
publishing details.
